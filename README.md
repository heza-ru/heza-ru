### Intro

**Mohammad Haider** — engineer, designer, and consultant.

I enjoy building fun little things — and shipping them with care. Interactive products, open-source CLI toys, weird web experiments, and agent/MCP tooling.

Portfolio: [haider.digital](https://haider.digital)

### Focus

| | |
|---|---|
| **Product engineering** | Interactive web apps, Tauri/desktop, Go CLIs — motion and performance as first-class concerns |
| **AI-assisted workflows** | MCP servers, Claude-powered assistants, structured agent tooling (`TeamFlow-MCP`, `enable` / `enablenext`) |
| **Craft & communication** | Demos, UX polish, READMEs that let someone run the thing |

Evidence for the craft brief lives on the site and in the featured repos below — not a badge wall.

### Featured work

**[Tuneminal](https://github.com/heza-ru/Tuneminal)** · Go · CLI  
Karaoke in the terminal: scrolling lyrics, live audio visualisation, scoring. Built for joy; recognised in GitHub’s *For the Love of Code* 2025 (**Terminal Talent**).

**[Netstalgia](https://github.com/heza-ru/Netstalgia)** · TypeScript · [Live demo](https://netstalgia.netlify.app/)  
A lovingly cursed 90s web fever dream on a modern stack — dial-up theatre, guestbook, dancing baby, the works. *For the Love of Code* 2025 (**World Wide Wonders**). Dual-category placement noted on the [winners announcement](https://github.blog/open-source/from-karaoke-terminals-to-ai-resumes-the-winners-of-githubs-for-the-love-of-code-challenge/).

**[Disactivity](https://github.com/heza-ru/Disactivity)** · Tauri 2 + React · ★40+  
Desktop game-activity simulator. Highest-star public original on this account; ships with a real README and release.

**[TeamFlow-MCP](https://github.com/heza-ru/TeamFlow-MCP)** · TypeScript · MCP  
Model Context Protocol server bridging AI clients to **Jira**, **Confluence**, and **Productboard** for ticket automation and knowledge retrieval.

**[Privasea](https://github.com/heza-ru/Privasea)** · Go  
Local-first privacy toolkit: broker opt-outs, legal-request automation, exposure scanning, on-device evidence.

**[Portfolio2026](https://github.com/heza-ru/Portfolio2026)** · React + Vite · [haider.digital](https://haider.digital)  
Source for the personal site — cinematic motion, custom type, enterprise + OSS storytelling.

### Open source — FULU Foundation

Contributions to **[FULU Foundation](https://github.com/FULU-Foundation)** (consumer ownership / right-to-repair nonprofit), not as a listed public org member — as an external open-source contributor.

**[FULU-Foundation/CRW-Extension](https://github.com/FULU-Foundation/CRW-Extension)** · TypeScript · ~★958 · [consumerrights.wiki](https://consumerrights.wiki)

Browser extension that surfaces Consumer Rights Wiki coverage while you browse. On the public contributors list I rank among the **top human contributors** (~9 commits). Merged work includes:

- [#161 — Popup position settings (four corners)](https://github.com/FULU-Foundation/CRW-Extension/pull/161)
- [#164 — Auto-dismiss with configurable timeout & progress bar](https://github.com/FULU-Foundation/CRW-Extension/pull/164)

Fork used for that work: [`heza-ru/CRW-Extension`](https://github.com/heza-ru/CRW-Extension).
